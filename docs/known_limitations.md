# 已知限制

> 对应版本：CodeMateKids 0.1.0（7 天 Windows Demo）
> 原则：未验证的能力不宣称已具备；以下限制应随演示一并说明。

1. **未完成操作系统级文件/网络隔离验证**
   本期提供受限执行、资源上限、最小环境变量、独立临时目录与整树终止，但未完成 AppContainer/ACL/网络策略等 OS 级隔离评审。对外演示不得宣称具备完整沙箱。

2. **内存上限依赖 Job Object，失败时降级轮询**
   Windows 上优先使用 Job Object 限制进程内存；若系统或权限不允许，退回轮询采样并终止，峰值内存无法精确拦截。启动页/矩阵/日志会记录实际模式（`job_object` 或 `polling`）。

3. **学习证据不落盘**
   证据仅存在于当前后端进程内存，刷新页面仍在同一会话，关闭进程即清空；总结页必须注明“仅代表本次会话观察”。

4. **真实模型模式未验证**
   Demo 验收以 `mock` 模拟模式为准；真实模型接入代码存在，但缺少账号、网络与配额验证，任何超时/无效输出都会立即回落预置回复。

5. **能力矩阵大部分条目未开始**
   本期只实现循环主题所需积木子集；矩阵中 `not_started` 与 `limited` 条目不得计为已支持。类定义与导入相关能力为策略拒绝。

6. **`pattern` / `handler` 端口仅预留**
   端口矩阵中保留 6 类端口，但循环主题不交付模式匹配与异常分支积木。

7. **前端交互以鼠标拖放为主，键盘支持有限**
   键盘可聚焦积木、上下移动焦点、删除、撤销/重做、运行、求助，并可用工具箱回车添加积木；0.2.0 起键盘插入与指针放置共用同一目标解析与事务规则。但仍未实现“键盘在任意插入位之间精确选择”和完整键盘拖放等价操作。

8. **触屏与移动端仍未验证**
   本期只面向 Windows 桌面鼠标 + 键盘；画布保留 `touch-action: none`，0.2.0 仅计划用 Chrome DevTools 模拟触屏/触笔，未做真机验证，移动端不在支持范围。

9. **运行启动开销受演示机环境影响**
   本机实测 Python 解释器冷启动在 0.24–1.13 秒之间抖动（裸 `python -c` 同样抖动）。运行器将启动与终止开销计入 500ms 余量；超时端到端实测 3482ms（3000ms 墙钟）。若演示机安全软件导致启动更慢，需要在验收记录中重新测量。

10. **鸿蒙示例未完成构建验证**
    本机未安装 DevEco Studio + HarmonyOS SDK，`harmony/` 仅交付 ArkTS/ArkUI 基础示例源码与阻断记录；不影响 Windows Demo 启动与教学闭环。

11. **浏览器端可交互启动时延与内存峰值未自动采样**
    API 层启动检查实测 378–455ms；浏览器首屏可交互时延、客户端常驻内存峰值需在演示机按 `docs/manual-checklist.md` 手工记录。

12. **未进行 60 分钟连续运行与真实断网演练**
    `mock` 路径没有外网依赖，但未执行物理断网与 60 分钟 10 次主流程观察，这两项在验收记录中标记为未验证。

13. **会话与运行状态为进程级共享**
    `SessionStore` 与 `RunManager` 的运行槽都是单个后端进程全局共享；当前仅承诺“回环地址、单人单浏览器”的演示环境。触发条件：监听非回环地址、预期 ≥2 浏览器/使用者、引入账号或会话身份、对外演示或远程访问。触发后需按 `design-bugfix-0.1.0.md` 2.4.18 增加会话身份与按会话分桶，当前不宣称具备会话隔离。

14. **标准错误摘要只进入开发诊断**
   worker 的 stderr 会被持续消费并生成 ≤160 字符的脱敏摘要，写入本地日志的 `stderrSummary`；运行结果 `stderr` 仍为空字符串，前端结果区不展示。摘要不面向儿童，也不等同于完整排障信息。

15. **最低支持窗口为 1024×768**
   布局已改为三段断点并去掉横向硬下限；低于 1024px 时显示最低尺寸提示条。仍不支持触屏与移动端，未完成真实浏览器低分辨率验收。

16. **浏览器全流程与稳定性仍未验证**
   自动化仅覆盖后端接口/运行器/前端纯逻辑与语法；真实浏览器拖放、SSE 时序、物理断网、取消/崩溃恢复、60 分钟连续运行与客户端内存峰值仍需按 `docs/manual-checklist.md` 手工验收。

17. **依赖版本以锁文件为准**
   `requirements.lock.txt` 记录当前环境可用的精确版本；`requirements.txt` 仍保留范围声明。干净环境能否完全复现需在独立虚拟环境执行 `scripts/bootstrap_env.cmd` 后再确认。
18. **表达式递归编辑未实现（0.2.0 路径 B）**
   当前课程已从两个任务移除 `value.number`/`value.calc`，工具箱不再显示无落点的值积木；表达式字段只显示只读摘要。未来开放需同时满足六项门槛：可运行表达式槽积木、递归布局与命中、树事务更新、序列化契约、后端契约测试、课程教学需求。其中序列化契约（`fieldName` 删除）已在模型层修复，其余未实现。

19. **后端未校验语句端口的节点类型**
   `validate_program()` 对 `next`/`body` 中的节点不校验端口类型，表达式节点出现在 `next`/`body` 时当前会被接受（`tests/test_program_expression.py` 已按现状固化）。前端由 `canConnect()` 阻止此类放置，但不构成后端兜底。

20. **ED-05 未经课程 UI 路径验证**
   `fieldName` 契约修复只经前端模型层 Node 断言与后端 pytest 闭环；当前课程没有表达式槽，无法通过课程 UI 路径复验。不得写成“UI 路径已验证”。

21. **0.2.0 的视觉与设备结论边界**
   无 Canvas 像素级自动化视觉回归；100ms 预览/提交时限未实测；真机触屏/触笔未验证（仅浏览器模拟）；Firefox/Safari 未纳入；1024×768 与 1280×720 需按 `docs/manual-checklist.md` 手工验收。
