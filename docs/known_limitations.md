# Windows Demo 已知限制

本页列出当前运行与验证边界。具体验收环境和数据以[验收记录](acceptance.md)为准。

## 运行范围与数据

- Demo 面向本机单人单浏览器。`SessionStore` 和 `RunManager` 由一个后端进程共享，学习证据随服务关闭清空。多人访问需要先加入会话身份和独立状态。
- Worker 提供白名单校验、独立临时目录与资源限制。操作系统级文件及网络隔离仍需单独验证。Windows 内存限制优先采用 Job Object，轮询降级时可能错过瞬时峰值。
- 开发日志包含限长、脱敏的 stderr 摘要。儿童界面读取结构化错误文案。
- 模型路径已有接入及回退逻辑，验收使用本地 `mock`。真实模型的网络、配额及回复质量仍待验证。

## 课程与编辑器

- 当前课程为循环主题，支持以「当开始」为起点的多组顺序脚本。模式匹配、异常处理、并行脚本和广播属于待扩展能力。 [能力矩阵](matrix.md)
- 重复次数、前进步数和转弯角度可接数字积木。四则运算用于表达式槽，作品草稿允许保留空表达式输入，运行前须补齐必填槽。 [作品契约](api-contract.md)
- 循环反馈使用当前运行事件。在行级事件缺失或截断时，界面提供自查提示。变式的结束语是可选加练。
- 键盘可选择积木和编辑参数，并可用工具箱添加、删除和撤销。任意嵌套插入位的精确键盘选择仍待扩展。指针捕获失败的回退有 Node 回归，浏览器故障注入仍待验证。

## 浏览器和设备

- Chrome 与 Edge 的无头自动化已覆盖 1280×720 和 1024×768 两档核心流程。缩放验证使用等效 CSS 视口和设备像素比。原生页面缩放、儿童试用、触屏和移动设备仍待验证。
- 首屏可交互时延、浏览器内存峰值、物理断网和 60 分钟连续运行仍待在演示机记录。编辑延迟的已有数据仅对应验收设备和示例程序。 [浏览器检查表](manual-checklist.md)
- 鸿蒙示例使用独立工具链，构建状态见[鸿蒙工程说明](../harmony/README.md)。

## 兼容与回滚

作品格式依照[当前接口契约](api-contract.md)验证。实际回滚演练仍待执行，回滚时以同一交付点的前端与课程包复验作品副本。

历史回滚方案及阶段结果见[拖放修复指南](toolbox-drag-and-nesting-fix-guide.md)、[交互恢复计划](interactive-blocks-recovery-plan.md)和[验收记录](acceptance.md)。

### 教学增强的验证边界

- 三类循环错因、预测归属、正方形结构与迁移帮助状态已通过 HTTP/SSE 回归。复杂程序或不完整的轨迹走通用反馈路径。回放最多展示 12 个动作，步数题中的可识别简单循环展示前两轮。
- 模型决策的请求形状和错误回复回退用模拟端点覆盖。真实模型端点的连通性、时延、表达质量，以及真实课堂的学习效果仍待验证。

### 网页模型与多轮辅导

- 网页配置、课堂回复、降级和多轮动作使用模拟上游验证。真实供应商的连通性、延迟和回复质量，以及 Chrome、Edge 的手工操作，留待填入模型配置后验收。
- 网页模型配置用于单机回环服务。网页适配器连到已校验的公开 IP，并使用原域名做 TLS 验证。公开部署需要独立的配置权限和会话方案。
- `CMK_TUTOR_AGENT_ENABLED=1` 启用同一题内的多轮选择。每个运行范围只保留最近 6 轮问答，修改程序或重新运行后使用当前运行证据。
