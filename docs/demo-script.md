# Windows Demo 演示脚本（约 8 分钟）

> 环境：Windows 10/11 演示机，Python 3.12，默认模拟模式（离线可走通）。
> 主题：循环——“让角色重复前进”。

## 演示前检查

1. `run_demo.cmd` 启动成功，启动条显示课堂就绪；点右上角“系统信息”，可看到 `Python 3.12.x（工作进程实测）`与课程/schema 版本。
2. 辅导区徽标为“演示回复”，说明本次不调用真实模型。
3. 课程区只突出当前任务“让角色走四步”，运行按钮因未预测而禁用。
4. “看代码”“检查明细”默认收起，需要时再展开，主工作区留给画布。

## 演示步骤

1. **进入课程**
   - 读学习目标：点“学习目标”展开，看出重复动作、用重复积木表达次数、检查实际步数。
   - 指出课程区没有“一键生成正确答案”入口。

2. **先预测**
   - 问孩子：现在的程序会让角色动几次？
   - 输入 `2` 并提交，运行按钮解锁，提示“预测记下了”。

3. **运行并观察**
   - 点击运行，画布逐块高亮，结果区首屏给出两句话：预测对照与实际动作次数、目标达成与差距。
   - 指出结果：预测 2 次 / 实际动了 2 次 / 目标 4 步，还差 2 步，任务未完成。

4. **第一次求助**
   - 点“轻提示”，小老师说“目标里要往前走几步？先数一数相同动作出现了几次。”
   - 强调：第一层不直接给完整答案。

5. **孩子修改**
   - 点击循环积木的“次数”字段，改成 `4`（或拖入新的重复积木重连）。
   - 说明一次拖动只产生一次撤销事务；Ctrl+Z 可撤销。

6. **再次运行**
   - 运行后角色累计走 4 步，结果区提示“这次做到了！”。
   - 对照预测：预测 2 次与实际 2 次一致，但目标已达成。

7. **重复困难场景（可选）**
   - 点“更多提示”，观察提示升级为执行过程/拆分步骤，且不原样重复第一句。

8. **变式任务**
   - 点当前任务区下方的“其他任务”，在展开的列表里点“开始这个任务”，进入“小海龟走六步”。
   - 先预测，再修改重复次数为 3（每次 2 步），运行到 6 步。
   - 说明变式换了角色与目标数量，检验迁移而不是原题换皮。

9. **学习总结**
   - 点顶部“学习总结”，展示本课概念、完成的任务、能独立做到的事、仍需验证方面与下一步建议。
   - 强调：不出现分数、排名、等级；注明仅代表本次会话观察。

10. **保存与恢复（可选）**
    - 点“保存作品”，得到本地 JSON；再点“打开作品”重新载入，结构保持一致。
    - 未知积木会被保留并标记“不可执行”。

## 演示话术要点

- Demo 验证的是功能闭环，不代表长期学习效果已被证明。
- 所有数据为虚构或当前会话临时数据，不使用真实儿童信息。
- 未验证项（OS 级沙箱、真实模型、鸿蒙构建）在 `docs/known_limitations.md` 中列明。
